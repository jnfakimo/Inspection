# RDQ 需求規格：功能室/會議室預約系統

## 一句話任務
在**臺北農產運銷股份有限公司 第一果菜市場**既有系統（`word-cloud-site` repo、共用 Supabase 專案 `qztffronusdhgxhjjubt`）裡新增第 7 個系統：內部員工登入後可預約會議室/功能室，送出即時生效並自動防止同時段重複預約。

## ✅ 已確認
- 整合進現有臺北農產系統，共用 Supabase 帳號與 RBAC，比照現有六大系統模式再加一張入口卡片（Ⅲ）
- 使用對象為內部員工，需要登入（沿用現有 `users`/`auth` 機制）（Ⅲ）
- 預約流程：送出即成功，**不需要人工審核**，系統自動擋掉同一房間同一時段的重複預約（Ⅲ）
- 採納：行事曆檢視（週/月視圖看全部房間排程）、超時未報到自動取消預約、到期前提醒通知（Ⅳ）
- 會議室**可定義多間**，且需要**後台管理介面**可新增/編輯（比照設備建置管理的模式，停用而非刪除）（Ⅲ，追加澄清）

## ❓ 假設（未確認，已採預設值，隨時可推翻）
- 每人/每部門預約則數、單次時長上限 → 預設**不設限**，之後有需要再加規則
- 「超時未報到自動取消」的報到方式 → 預設參考既有巡邏簽到模式，**到場手動按「報到」**，寬限 **15 分鐘**未報到即自動釋出（可調整）
- 提醒通知管道 → 預設沿用現有巡檢逾時推播用的 **LINE Notify + Supabase Edge Function** 排程機制，不做 Email
- 系統層級權限 → 預設新增 `sys_meetingroom` 存取權限鍵，**比照現有「系統存取權限」機制全角色預設開放**，之後可在 RBAC 頁面收緊
- 是否需要稽核紀錄 → 預設沿用剛做好的 `audit_logs` 機制，記錄新增/取消預約
- 資料表雛形：`meeting_rooms`（room_id, name, capacity, floor, status）、`meeting_bookings`（booking_id, room_id, user_id, start_time, end_time, purpose, status[booked/checked_in/cancelled/expired], created_at）

## ➕ 已採納（象限Ⅳ）
- 行事曆檢視（週/月視圖看全部房間排程）
- 超時未報到自動取消預約
- 到期前提醒通知（LINE）

## ❌ 排除項（明確不做）
- 會議室資源清單（投影機/白板/視訊設備篩選）— 這次先不做，之後如需要再加 `equipment` 欄位或關聯表
- 對外開放（外部單位/民眾預約）— 這次只做內部員工
- 人工審核流程 — 這次不做，全部自動生效

## 📋 一段式需求規格
為**臺北農產運銷股份有限公司 第一果菜市場**的 `word-cloud-site` 系統新增第 7 個子系統「功能室/會議室預約系統」，與現有六大系統（後台管理、報修派工完工、駐衛警巡檢、電子交接簿、設備建置、專案關係圖）並列於 `system/index.html` 入口頁，共用同一套 Supabase 專案（`qztffronusdhgxhjjubt`）、同一套帳號登入與 RBAC 系統存取權限機制（新增 `sys_meetingroom` 存取鍵，比照既有 6 個系統的預設全開、後續於 RBAC 頁面收緊的模式）。使用對象僅限已登入的內部員工。核心資料表為 `meeting_rooms`（會議室主檔，**可定義多間**，含房號、名稱、可容納人數、所屬樓層、狀態）與 `meeting_bookings`（預約紀錄，含房間、使用者、起訖時間、狀態），會議室主檔需要**後台管理介面**（比照後台既有的設備建置管理模式，管理者可新增/編輯會議室，停用而非刪除）。預約送出後**立即生效、不需審核**，系統以起訖時間重疊檢查自動阻擋同一房間同一時段的重複預約。畫面需提供**週/月行事曆視圖**檢視全部房間的排程總覽。使用者到場需**手動報到**，超過寬限 **15 分鐘**未報到即自動將該筆預約標記為過期並釋出房間；到期前另有 **LINE 提醒通知**（沿用現有巡檢逾時推播的 Supabase Edge Function 排程架構）。所有新增/取消預約動作寫入既有 `audit_logs` 稽核紀錄。本次**不做**會議室設備篩選、對外公開預約、人工審核流程，這些留待日後有需求再擴充。

## ✔ 驗收條件
- [ ] 入口頁 `index.html` 出現第 7 張「會議室預約系統」卡片，且會依 `sys_meetingroom` 權限顯示/隱藏
- [ ] 內部員工登入後可看到行事曆視圖，選擇房間與時段送出預約，同時段同房間第二次預約會被系統擋下
- [ ] 到場報到後預約狀態變更；超過 15 分鐘未報到的預約自動變成已取消，房間釋出
- [ ] 到期前收到 LINE 提醒通知
- [ ] `audit_logs` 能查到該次新增/取消預約的紀錄
