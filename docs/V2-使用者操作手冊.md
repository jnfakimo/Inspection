# 北農整合管理系統 V2 使用者操作手冊

版本：V2｜適用對象：一般使用者、單位主管、作業人員、系統管理員

## 1. 系統入口

- 系統首頁（戰情儀表板）：<https://jnfakimo.github.io/Inspection/v2/>
- 登入：<https://jnfakimo.github.io/Inspection/v2/login/>
- 帳號申請：<https://jnfakimo.github.io/Inspection/v2/account-apply/>
- 系統入口：<https://jnfakimo.github.io/Inspection/v2/systems/>
- 行動版：<https://jnfakimo.github.io/Inspection/v2/mobile/>

V2 使用同一組登入與人員資料。登入後只會顯示目前帳號被授權的系統；看不到某個功能時，先確認帳號是否啟用、角色是否包含該系統，必要時請系統管理員處理。

## 2. 登入、帳號申請與個人資料

### 2.1 登入

1. 開啟登入頁，輸入登入帳號與密碼。
2. 按「登入」。登入成功後會依原目的地返回，沒有目的地時進入戰情儀表板。
3. 右上角會顯示所屬單位、姓名、連線狀態與台北時間。
4. 作業完成後按「登出」；共用電腦不可只關閉瀏覽器分頁。

### 2.2 申請系統帳號

1. 在登入頁進入「申請系統帳號」。
2. 填寫姓名、登入帳號、電子郵件、電話、所屬課室與申請說明。
3. 輸入圖中的六位數安全驗證碼；看不清楚可按「重新產生」。
4. 按「送出帳號申請」。申請完成後等待系統管理員審核。
5. 核准後，系統會寄送設定密碼連結到申請信箱。

系統角色與直屬課室主管由系統管理員核定，申請人不能自行選擇或提高權限。

### 2.3 個人資料與密碼

登入後按右上角「個人資料」可：

- 修改姓名與聯絡電話；帳號、電子郵件、所屬單位與角色由管理員維護。
- 修改登入密碼。新密碼須符合畫面顯示的長度與複雜度要求。
- 連結或解除自己的 Google 個人行事曆（會議室預約同步用）。

## 3. 共用導覽與基本操作

頂列共用動作依序為：首頁、戰情儀表板、維修／派完工、駐衛警巡檢、電子交接簿、後台。權限不足的動作會自動隱藏。

各列表頁的共通操作：

- 先用關鍵字、狀態或日期篩選，再按搜尋或套用。
- 表格若有分頁，切換頁碼不會改變資料；完成新增／修改後應重新整理確認。
- 看到「無權限」或「拒絕存取」時不要重複嘗試，請記下時間、頁面與操作後通知管理員。
- 上傳附件前確認檔案內容不含不必要的個人敏感資料；私有附件只能在登入且有權限時開啟。

## 4. 維修／派工／完工

入口：<https://jnfakimo.github.io/Inspection/v2/systems/workorder/>

標準流程：**報修 → 單位主管確認／派工 → 維修人員接單 → 維修處理 → 報修人驗收 → 主管結案**。

### 一般使用者／報修人

1. 進入「報修案件」，按「新增報修」。
2. 填寫故障位置、故障說明、聯絡資訊與希望完成日期，依畫面要求附上現場照片。
3. 送出後在案件詳細頁查看案件編號、目前狀態與歷程。
4. 維修完成後檢查處理結果；不符需求時退回並補充說明，符合時送出驗收。

### 單位主管／派工人員

1. 在報修案件或派工作業中查看待處理案件。
2. 確認故障內容、位置、優先順序與附件。
3. 指派適當的維修人員，必要時退回補件。
4. 檢視維修回報與驗收結果，確認後完成結案。

### 維修人員

1. 開啟被指派的案件並按「接單」。
2. 更新處理進度、原因、處置內容與使用材料，必要時補上照片。
3. 完工後送出維修回報，等待報修人驗收。

## 5. 公務車派車

入口：<https://jnfakimo.github.io/Inspection/v2/systems/vehicle/>

標準流程：**一般使用者申請 → 單位主管核可／退回 → 派車管理員派車 → 駕駛接單 → 行車回報 → 派車紀錄**。

1. 申請人填寫用車日期、時間、目的、起訖地點、人數與備註後送出。
2. 單位主管檢查用途與必要性，選擇核可或退回並留下原因。
3. 派車管理員選擇可用車輛與駕駛，完成派車。
4. 駕駛確認派車內容後接單；行程結束填寫里程、時間與必要的行車回報。
5. 所有狀態變更與操作人員可在「派車紀錄」查詢。

未通過上一階段核可的申請，不會進入下一階段；不要以其他角色帳號代操作。

## 6. 駐衛警巡檢

入口：<https://jnfakimo.github.io/Inspection/v2/systems/guardpatrol/>

- 「巡邏打卡」：依班別與巡邏點完成簽到，確認時間、位置與現場狀況。
- 「巡邏點清單」：查詢巡邏點、樓層與 QR 標籤位置。
- 「巡檢排班」：管理當日班別、人員與預定時段。
- 「逾時推播」：查看通知結果與失敗原因。
- 「設備巡檢」：填寫設備運轉狀態；選擇異常時必須補充說明。
- 「立體巡檢雲臺」：依樓層查看巡檢點與當日狀態。

行動網路不穩時，先確認畫面是否顯示離線暫存；恢復連線後確認補傳結果，不要連續重複打卡。

## 7. 電子交接簿

入口：<https://jnfakimo.github.io/Inspection/v2/systems/handover/>

1. 新增交接紀錄，確認日期、班別與接班人。
2. 檢查系統帶入的設備運轉摘要與當日報修概況。
3. 逐項填寫異常與未結事項，附上必要說明或附件。
4. 先儲存草稿，確認內容後送出交接。
5. 接班人開啟紀錄並完成接收；後續事項在「未結事項」追蹤。

交班人與接班人不可為同一人；過去班次不可補填成目前班次。

## 8. 設備建置系統

入口：<https://jnfakimo.github.io/Inspection/v2/systems/equipment/>

可依權限使用設備主檔、保養排程、維修履歷、維護合約、設備文件、年度成本、中央監控與材料主檔。新增或修改主檔時，請先確認資產碼、所在樓層／區域、設備狀態與負責單位，再儲存並重新查詢確認。

## 9. 專案關係與設備圖臺

入口：<https://jnfakimo.github.io/Inspection/v2/systems/structuremap/>

- 「區域位置表」：查詢樓層、區域與空間資料。
- 「整合標記系統」：在平面圖上查詢設備、空間、巡邏點與報修標記。
- 「平面樓層圖」：切換樓層、縮放與平移高解析度圖面。
- 「3D 模型圖」：切換樓層並旋轉、縮放立體模型。
- 「圖資專案設定」：由 3D 建模系統管理共用圖資來源。
- 「專案關係圖」：唯讀查看子系統與資料關係。

3D 建模系統是唯一圖資來源；不要在整合標記、2D 與 3D 頁面各自上傳另一份圖檔。圖面載入需要登入與有效權限，載入失敗時先重新登入，再回報樓層與時間。

## 10. 會議室預約

入口：<https://jnfakimo.github.io/Inspection/v2/systems/meetingroom/>

1. 先選會議室、日期、起訖時間與用途。
2. 送出前確認沒有與既有預約衝突。
3. 需要改期或取消時，使用「變更申請」並填寫原因。
4. 「預約提醒」查看通知狀態；Google 行事曆同步須先在個人資料中完成本人帳號授權。

## 11. 公文傳送系統

入口：<https://jnfakimo.github.io/Inspection/v2/systems/officialdocs/>

1. 原申請人建立公文，填寫公文主旨與公文編號；系統會產生查詢用條碼。
2. 單位公文管理人員選擇下一個會辦部室送出；前一個會辦完成後，才能選擇下一個會辦或陳核部室。
3. 會辦單位收發人員先按「收文」，完成會辦後按「會辦完成」。陳核單位先按「簽收」，再按「核決完成」。
4. 核決完成會送回原申請人；原申請人按「收訖」結案。退回時可補正後按「補正後重新送出」，原歷程不會被覆蓋。
5. 條碼掃描與主旨查詢只會開啟公文，不會自動收文或簽收；可在公文頁產生、下載或列印條碼。

每個送出、收文、會辦完成、簽收、核決、退回、補正重送與收訖均保留操作者、角色、部室、伺服器時間與前後狀態；重複操作不會產生第二筆事件。逾期未收文／未核決由排程建立承辦人與主管的站內通知。

## 12. 後台管理（授權人員）

入口：<https://jnfakimo.github.io/Inspection/v2/systems/admin/>

- 人員帳號：審核申請、啟用／停用帳號、設定單位與直屬主管。
- 角色權限：由管理員定義角色可使用的系統；採最小權限原則。
- 場域位置：維護市場、樓層、區域與巡檢位置。
- 操作稽核：查詢登入、資料存取、權限拒絕與管理操作。
- 資安告警：處理大量讀取、拒絕存取、暴力登入、系統錯誤等事件。
- 通知中心：查看通知內容與處理狀態。
- 戰情版面：管理儀表板元件與版面版本。
- 巡檢週期：開啟週期與查看週期歷史。
- 費用統計：查看設備生命週期費用。
- 位置分析：依市場／樓層／區域分析巡檢與報修。
- 系統健康：查看前端錯誤與介接異常。

管理員不得以共用帳號操作；停用人員採停用帳號，不刪除歷史資料。資安告警若涉及大量讀取、連續拒絕存取或疑似暴力登入，先保留告警編號、時間、資源與處理人，再依資安通報流程處理。

## 13. 異常處理與回報格式

遇到錯誤時，請提供：

1. 操作日期時間（台北時間）。
2. V2 網址、系統與子功能。
3. 使用者角色與操作步驟（不要提供密碼或 Token）。
4. 畫面錯誤文字、案件／申請編號及是否可重現。
5. 若為圖臺，補充樓層、瀏覽器與是否已重新登入。

建議先依序嘗試：重新整理 → 確認網路 → 登出再登入 → 清除該頁快取或以無痕視窗重試。若畫面顯示「安全控制已啟動」或被強制登出，不要連續重試，直接通知管理員查閱「資安告警」與「操作稽核」。

## 14. 權限與安全注意事項

- 不共用帳號、不代替他人核可、不使用他人密碼。
- 不把密碼、Access Token、服務金鑰或備份密語貼在訊息、截圖、試算表或原始碼。
- 報修照片、交接附件與圖面資料依權限使用，不另行公開分享下載網址。
- 下載、匯出或大量查詢前先確認業務必要性；大量自動讀取可能觸發資安控制。
- 離開工作站前登出，手機遺失或帳號疑似被使用時立即通知管理員停用帳號並保留告警資訊。
