## 發現與修正

### 行動加密儲存

修正檔案：`mobile/vehicle-tracker/src/encrypted-storage.ts`。三個反例在修正前均失敗，修正後通過：

| 問題 | 可重現影響 | 修正 |
|---|---|---|
| 大筆資料在第二段或索引寫入失敗 | 新分段殘留，重試會累積無主資料 | 失敗後讀回索引，只清理已確認未發布的新世代；保留舊世代。若原生層已提交卻回報失敗，不刪除現行世代 |
| 登出遇到破損 JSON／非法分段引用 | 解析錯誤使索引與舊登入資料未刪除 | 無效引用不採信，仍移除該項索引與舊資料；不刪除他項儲存鍵 |
| 登出與先前尚未完成的寫入競態 | 登出完成後先前寫入才落盤，登入資料重現 | 同一鍵的讀取、遷移、寫入與移除依呼叫順序序列化；失敗不阻塞後續操作 |

保留限制：鎖只涵蓋同一 JavaScript 執行個體；突然斷電、跨原生執行個體、實際磁碟故障仍需實機驗證。索引毀損後無法信任的分段、讀回失敗或清理也失敗時可能保留密文殘片，不能宣稱完成實體抹除。沒有改動密碼、加密格式、金鑰名稱或資料保存政策。
