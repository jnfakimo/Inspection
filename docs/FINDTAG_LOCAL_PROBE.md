# FindTag 桌機資料讀取：第一階段

## 目的與目前邊界

沿用使用者已登入的 FindTag Android App，不要求安裝另一套手機 App，也不擷取原廠登入密碼、權杖或 Cookie。本階段只驗證桌機上可見資料能否穩定讀出；**不是原廠 API 介接，也不是正式 GPS 自動同步**。

2026-09-08 已確認 BlueStacks 的本機 ADB 可連線，FindTag 套件為 `com.lq.position`，版本 `1.2.27`（版本碼 `47`）。設備清單的可見文字結構提供標籤名稱、地址文字與原始定位時間；檢查過的地圖與清單沒有提供數值經緯度。

設備詳細頁另有 MAC 位址，但不能依同名標籤自動關聯不同裝置。此次桌機設備與先前手機截圖的識別碼不同；未核對前，不把兩者當成同一顆設備，也不建立正式車輛映射。

## 單次讀取方式

1. 使用者本人在 BlueStacks「設定 → 進階」啟用 Android 調試橋並儲存；不開放到區域網路。
2. 保持 FindTag 已登入，回到地圖首頁，點左上角圖示展開底部設備清單。
3. 執行本機工具：

   ```powershell
   python tools/findtag-visible-probe.py --adb "C:/Program Files/BlueStacks_nxt/HD-Adb.exe"
   ```

4. 工具只執行一次，讀取可見清單；不自動切頁、點擊、登入、授權或配對。

工具限已核實的 `127.0.0.1:5555`。非 FindTag 首頁、版本不符、未授權、連線逾時或清單結構不明時停止，不猜測內容。真實輸出只留在 `%LOCALAPPDATA%/Beinong/FindTagProbe/`，不放 repository、OneDrive、靜態網站或公開建置產物。

這是本機檔案，不是加密雲端備份；可存取此 Windows 使用者資料夾的人可能讀到內容。Codex 的 MSIX 執行環境可能將此邏輯位置導向同一本機資料夾下的應用程式快取；工具在建立後重新驗證實際路徑，不能因重新導向而允許寫到公開專案或同步資料夾。終端僅顯示筆數與能力摘要，不列出地址、設備名稱或完整原始 XML。

## 資料解讀

- **地址觀測**：來自原 App 清單顯示的文字，不做地址轉座標，不冒充原始 GPS。
- **定位時間文字**：保留原畫面時間。來源時區未核實前，不擅自轉成 UTC。
- **擷取時間**：代表桌機何時讀到畫面，不是車輛何時定位。
- **識別碼**：本工具不把清單名稱當成唯一設備 ID；外部設備與車輛映射仍待核實。
- **經緯度／精度**：未取得即保持空值，不從地址數字、地圖中心或圖釘像素推算。
- **去重**：相同可見內容不產生新定位事件；重新讀到舊畫面不代表車輛在線或位置更新。
- **範圍**：只涵蓋當下可見清單，未顯示或需捲動的設備不保證已採集。介面變更時必須重新驗證欄位。

## 安全邊界

不執行 root、run-as、模擬點擊、封包攔截或私有資料庫抽取；不變更 App 安全／隱私設定。Android 端只在 ADB shell 暫存區 `/data/local/tmp` 產生本工具專屬、隨機命名的 XML；先將自建檔案權限設為 `600`，再輸出可見結構，讀取後清理，不刪除其他檔案、不使用共用下載資料夾。此路徑不是 FindTag 私有資料庫。正常失敗會清理；作業系統或程序被強制中止時不能保證清理，因此不把它當永久資料來源。失敗不得輸出原始命令回應中的敏感資料。

ADB 已開啟時只使用本機通道；測試結束或不再需要讀取時，由使用者本人在 BlueStacks 關閉 ADB。不得為了方便而修改防火牆、開放外部監聽或略過授權提示。

## 後續介接前置條件

1. 核對要串接的實體標籤及車輛，建立明確映射。
2. 若需求是精確定位與軌跡，需取得原廠授權 API 或含經緯度的正式匯出；僅有地址觀測不能驗收 GPS 功能。
3. 原 FindTag 登入留在 App；公司網站仍沿用自己的帳號權限。正式收集器應使用僅限指定來源／設備、可撤銷的上傳憑證，不使用管理員 Session 或 service-role key。
4. 新增獨立第三方觀測接收層與權限測試，不能將地址資料灌入現有手機勤務定位表，否則會污染里程、停留及圍籬告警。
5. 網站分開顯示原廠定位時間、最後同步時間、來源、資料品質與錯誤；先驗證重讀去重、過期資料、斷線及越權拒絕，再考慮排程。

## 回歸測試

```powershell
python tools/findtag-visible-probe.test.py
```

24 項測試通過，只使用合成 XML 與替身 ADB，不連正式 App、不存真實位置。另由代理在已授權桌機實測讀到 1 筆可見觀測；再次讀取時，私人結果檔的 SHA-256 與修改時間均保持不變，經緯度、來源 UTC 及外部設備映射保持空值。暫存檔實測權限為 `600`，執行結束後確認無本工具殘留檔。

正式資料庫、網站上傳、跨裝置映射與長時間無人值守同步不在本階段驗收範圍。工具目前是單次串行執行，不應同時啟動多個收集程序；增加排程前還需補收集器互斥、長期錯誤監控與保留政策。
