# 系統架構

返回：[[00-專案首頁]]

## 前端

- 純 HTML、CSS、JavaScript，多頁式架構。
- 頁面位於 `system/*.html`，每頁可獨立運作。
- UI 使用繁體中文與深色科技風格。
- 外部套件透過 CDN 載入。

## 後端

- Supabase PostgreSQL：業務資料。
- Supabase Auth：帳號登入與工作階段。
- Supabase Storage：平面圖與報修附件。
- Supabase Edge Functions：LINE 通知等伺服器端功能。

## 圖資

- OpenSeadragon：2D 深度縮放平面圖。
- Three.js：3D 樓層檢視。
- `system/plans/`：正式使用中的 DZI 圖磚與材質，禁止任意刪除。

## 資料流

使用者 → GitHub Pages 靜態頁面 → Supabase API → PostgreSQL／Storage／Edge Functions
